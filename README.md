# Personal Expense Tracker

A simple Python-based Personal Expense Tracker that helps users record, manage, and keep track of their daily expenses.

## About the Project

Managing small daily expenses can become difficult when they are not recorded properly. This project was created as a simple solution to keep track of personal spending in an organized way.

The Personal Expense Tracker allows the user to enter their expenses, store the information, and view their spending details whenever needed.

## Features

* Add new expenses
* Record the amount spent
* Categorize expenses
* Store expense details
* View previously recorded expenses
* Calculate total expenses
* Simple and easy-to-use interface
* Helps understand personal spending habits

## Technologies Used

* **Python**
* Python functions and conditional statements
* Lists / dictionaries for handling data
* File handling for storing information

## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

You can check it using:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone <your-github-repository-link>
```

### 3. Open the Project Folder

```bash
cd Personal-Expense-Tracker
```

### 4. Run the Program

```bash
python main.py
```

Follow the instructions displayed by the program.

## How It Works

The program takes expense information from the user and processes it according to the available options.

A typical workflow is:

```text
Start
  ↓
Open Expense Tracker
  ↓
Choose an option
  ↓
Add / View / Calculate Expenses
  ↓
Enter or retrieve expense information
  ↓
Display the result
  ↓
Exit
```

## Example

A user can enter an expense such as:

```text
Expense: Lunch
Category: Food
Amount: ₹120
```

The expense is then recorded and can be included when calculating the user's total spending.
